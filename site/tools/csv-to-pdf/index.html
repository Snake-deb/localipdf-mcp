CSV to PDF

Turn comma-separated data into a readable PDF table.

Enable JavaScript in your browser to use this tool.

CSV to PDF help

Create a PDF table from comma-separated data. Preview the rows, choose a paper layout and download a new copy. Leading zeros, decimal values and quoted text stay as written. Formulas are printed as text; they are never calculated.

How to use CSV to PDF

  1. Select Open CSV file or paste comma-separated data into CSV.
  2. Check the Live preview, especially columns, quotes and important values.
  3. Choose your paper size, orientation, text size, line spacing and margins. Leave First row is a heading on when the first row contains column names; turn it off when every row is data.
  4. Select Create PDF, review its pages and select Download PDF.
Options explained
First row is a heading
On by default. The first row is bold and repeats on later table pages. Turn it off when every row contains data.
File name
Choose the name for the downloaded PDF; the CSV original stays unchanged.
Paper size
Choose A4, Letter or A3. Wider paper can help tables with more columns.
Orientation
Choose portrait or landscape. Landscape gives wide tables more room.
Text size
Choose 8–36 points. Smaller text can help long values fit; always check readability.
Line spacing
Choose spacing for multiline cells. Rows stay together where they fit; a row too tall for a page is reported.
Margins (mm)
Choose 5–50 mm of space around the table.
Process all files
Create a separate PDF for each selected CSV with the same settings. Failures are reported separately; download individual copies or a ZIP.
Clear text
Remove the current input and PDF from this workspace. Refresh also clears working files.
Limits and supported files

Comma-separated CSV in UTF-8 or BOM-marked UTF-16, or pasted CSV. Quoted commas, doubled quotes and multiline fields are supported. Use the same number of columns in every row.

Files up to 2 MB can be read; the table input is limited to 50,000 characters. Very wide values or a row taller than the page need smaller text, wider paper or a smaller section.

Up to 1,000 rows and 12 columns. The shared table builder has a 500-page output limit. These are enforced bounds, not a guarantee for every device.

Use a current browser. Results from browser tests are recorded separately and do not guarantee that every file will finish.

Up to 100 selected files and 512 MB combined, subject to the per-file limits. An individual failure does not stop the other files.

Questions

Will leading zeros or decimal values change?

Values stay as text: 00123 stays 00123 and 123.450 stays 123.450. The tool does not round numbers, convert dates or calculate formulas.

Can a cell contain a comma, quote or several lines?

Yes. Put a field containing a comma or line break inside double quotes. Inside a quoted field, write two quotes for one literal quote. The preview shows the resulting table.

Does the first row have to be a header?

No. First row is a heading is on by default because most CSV files start with column names. Turn it off when every row is data.

Can I convert a semicolon-delimited file or Excel workbook?

This tool accepts comma-separated CSV, not semicolon-separated exports or Excel workbooks. Export a comma-separated CSV first. Spreadsheet formatting, merged cells, images and formulas are not reconstructed.

What happens if a row has fewer columns?

The tool asks you to correct it. It does not silently move values to guessed columns or discard rows. Check quoted commas and empty fields.

Can I create this PDF offline?

Yes, after the app's processing files finish downloading. The CSV, preview and output remain on your device. Refresh clears working files; download the result first.
