Watermark PDF help

Add a text or image watermark to PDF pages. Use a visible label such as Draft, or add your own mark while keeping the document readable.

How to use Watermark PDF

  1. Choose your PDF, then choose Text watermark or Image watermark and add your text or picture.
  2. Set Visibility and Position. Open More options for rotation, repetition and text formatting.
  3. Check the preview. Use Choose pages to mark only some pages, then click Add watermark.
  4. Click Download and check the saved pages to make sure the watermark leaves the document readable.
Options explained
Choose pages
Mark all pages, or open Choose pages to select a range or individual pages.
Page shortcuts
Use All, None, Odd, Even, Portrait or Landscape to select matching pages.
Watermark text
Enter a label such as Draft when a text mark is enough.
Image watermark (JPG / PNG / WebP)
Choose a logo or picture instead of text; use Image width (% of page) to size it.
Rotation (degrees)
Angle the mark across the page.
Repeat across page
Tile the mark; Horizontal gap (mm) and Vertical gap (mm) set the spacing.
Layer
Above content stays visible over the page; Below content may be hidden by opaque backgrounds.
Font and Text size
Choose a text style and size; Noto Sans supports Latin, Greek and Cyrillic.
Color and Visibility
Set the mark color and visibility so the document remains readable.
Position and Margin (mm)
Choose where the mark sits and its distance from the visible page edges.
Preview before export
Switch between With current settings, Original and Side by side to check the placement before exporting.
Start live preview
Smaller PDFs preview automatically. Use Start live preview for larger files, or Pause while editing. Zoom affects only the preview.
Jump to page and Thumbnail size
Use Go to locate a page and adjust the size of its preview. These viewing controls do not resize the exported pages.
All, None, Odd, Even and Select range
Open Choose pages and select thumbnails, use a shortcut, or enter numbers such as 1,3,5-10 and click Select.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

Watermark PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Does a watermark prevent copying?

No. A watermark is a visible mark, not a guarantee against copying or editing. Choose a position and appearance that communicate your message without obscuring the document.

Can a watermark remove information underneath it?

No. Covering content with text or a picture is not permanent removal. Use Redact PDF for confidential information, and check the finished redacted copy before sharing.

Can I watermark only selected pages?

Yes. Open Choose pages, then select page thumbnails or enter a range and click Select.

Can I put a watermark only on odd or even pages?

Yes. Open Choose pages and use the Odd or Even shortcut.
