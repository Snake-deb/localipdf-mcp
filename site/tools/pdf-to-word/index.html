PDF to Word help

Convert PDF pages into a Word document with editable text or page pictures. Choose editable text for revising words, or page pictures when keeping the visible layout matters most.

How to use PDF to Word

  1. Choose your PDF and set Pages (leave blank for all).
  2. Choose Word format: Editable text or Keep page appearance; review the picture and paragraph options if shown.
  3. Select Convert to Word and read any conversion notes.
  4. Select Download Word, open the document and check paragraphs, tables and numbers.
Options explained
Pages (leave blank for all)
Limit conversion to the chapters or pages needed in Word.
Word format
Editable text produces editable words and supported simple tables. Keep page appearance inserts page pictures instead.
Include original page pictures after the text
Adds a picture of each original page after its text. Turn it on to keep drawn charts and diagrams, or to compare the result with the original. It makes the Word file much larger.
Join wrapped text into paragraphs
Join ordinary prose lines for easier editing; leave off for forms or unusual layouts.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.

Questions

Will the Word file look exactly like the PDF?

Editable text keeps extracted words and approximate formatting, but complex layouts can change. Some simple tables become Word tables. Page pictures retain the visible appearance, but text inside those pictures is not editable.

Can I convert a scanned PDF into editable text?

A scan without selectable text stays a picture in this converter. Run OCR first if you need recognized text, and check names, numbers and tables carefully. Recognition and layout reconstruction are not guaranteed.

What does joining wrapped text do?

The optional paragraph setting joins ordinary lines of prose into editable paragraphs. Leave it off when preserving separate lines is more useful. Review unusual columns, lists and page breaks after conversion.

Can I convert only part of a PDF to Word?

Yes. Enter a page range, such as 2-5, in Pages before converting. Leave it blank to convert all pages. The result downloads as a DOCX file for Word.
