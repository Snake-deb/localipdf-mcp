Edit PDF

Change text in simple PDFs, or cover old words and retype them.

Enable JavaScript in your browser to use this tool.

Edit PDF help

Change supported words and numbers inside a PDF and save a new copy. Simple text using common fonts can be edited directly. The tool does not silently cover original text. For unsupported text, pictures, notes and drawings, use Add visible changes to open Annotate PDF instead.

How to use Edit PDF

  1. Choose your PDF, then choose a page from the page list.
  2. Click a marked text area or choose it in Text area. Check Original text and enter New text.
  3. Select Apply text change. Repeat for any other supported areas. Undo and Redo let you review your changes.
  4. Select Save edited PDF to see the actual updated page. Review it and select Download edited PDF.
Options explained
Text area
Choose one of the supported text areas on the current page. Only areas that can be changed directly are marked. An unmarked area might be a picture, use a custom font or have a layout that this editor cannot safely modify.
New text
Use letters, numbers and punctuation from English or other Western European languages, including accents, dashes and €. Keep the new text within the original space; a longer replacement may not fit. An empty replacement removes the selected text from the page.
Apply text change
Apply this change to the edited copy. Your original stays unchanged. Select Save edited PDF to generate the preview and download; typing alone does not save changes.
Undo and Redo
Step backward or forward through applied text changes. Any change clears the previous download so it cannot be mistaken for the latest copy.
Cover and retype
Open the current copy in Annotate PDF to add styled text, pictures, highlights, notes and drawings. You can choose a visual cover and replacement text after confirming that the old words stay in the file. These are visible additions, not direct edits to unsupported original text.
Process all files
Apply the selected changes to each chosen file only when the original text and supported area match. Mismatched or locked files fail separately. Review every result; page layouts can differ.
I understand the digital signature will no longer verify in this edited copy.
Editing changes the signed document. When a signature is detected, acknowledge that it will no longer verify in this edited copy. Keep the original signed file.
Limits and supported files

Readable PDF files with text in the standard PDF fonts. If an opening password is required, use Unlock PDF first. Scans and unsupported font/layout structures need another editing approach.

Inputs must be smaller than 128 MB. Each decoded page-content stream is limited to 4 MB. These bounds protect browser memory; they do not guarantee that every document will complete on every device.

Up to 200 pages per document, two million supported text characters, 2,000 supported areas per page and 500 different applied text changes. Each replacement supports up to 2,000 characters and must fit its original space.

Use a current browser. Review your exported copy in your normal PDF reader, particularly important words and numbers. Browser-engine tests do not replace checking your own device.

Up to 100 selected files and 512 MB combined, subject to the individual input limits and matching-text checks. Batch failures do not replace the other files' results.

Questions

Can every PDF word be edited?

No. Direct editing works on separate lines of text in the standard PDF fonts, such as Helvetica, Times and Courier, including on pages with pictures and drawings. Embedded or custom fonts, rotated text, scanned words and complex spacing are not edited directly. Use Add visible changes to open the annotation tool for these areas.

Does this draw a white rectangle over the old words?

No. Direct edits replace the text instruction for that page. The original font, size, position and colour remain. Visual additions in Annotate PDF are a separate option.

Can I use this to hide private information?

Use Redact PDF for that. Editing changes the displayed page text, but unused original objects or other copies of the same information can remain in a PDF. It is not secure redaction.

What happens to form fields and other pages?

Direct editing keeps the document's other page objects and saved form fields. Shared page content is copied for the changed page so another page is not changed accidentally. Review the downloaded file in your usual PDF reader.

What if the new text is too long?

The tool asks you to shorten it to fit the original space. It does not shrink the font, wrap the line or move nearby information automatically.

Are my files uploaded or saved after refresh?

No. Processing and preview happen in the browser. Refreshing clears the selected PDF and edits. Website analytics do not receive document content, filenames or passwords.
