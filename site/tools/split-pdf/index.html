Split PDF

Separate a PDF into pages, ranges, or smaller documents.

Split PDF help

Separate one PDF into smaller documents by page or page range. Use it to send a chapter, divide a large report or keep several sections as separate files.

How to use Split PDF

  1. Choose the PDF you want to divide.
  2. Choose Split mode: Every page for individual files, Custom ranges for chosen sections, or another method that matches your document.
  3. Enter Page ranges or Pages to split after, or set Pages per file for equal-sized sections. Choose Keep bookmarks if needed.
  4. Click Split PDF. Download individual results or use Download ZIP to save them together.
Options explained
Split mode
Every page creates one file per page. Custom ranges creates a file for each entered range. Same number of pages per file makes equal-sized sections, with a shorter final file if needed. Odd pages or Even pages keeps only that group. Split after pages uses your chosen boundaries. At each bookmark starts a file at each supported page-linked bookmark; it needs bookmarks in the source.
Page ranges and Pages to split after
In Custom ranges, enter separate sections such as 1-3,4-6. In Split after pages, enter the last page of each part, such as 3,7.
Pages per file
Set the size of each section when splitting by a fixed page count; the last file can be shorter.
Keep bookmarks
Keep supported navigation entries whose destinations remain in each output.
Make form entries permanent
Shown when a PDF has interactive form fields. Keep the visible answers while making them uneditable in the new file. Digital signatures will no longer verify; keep the signed original.
Undo and Redo
Step backward or forward through workspace changes before saving. Your original PDF is not overwritten.
Jump to page and Thumbnail size
Use Go to find a page preview, or resize the previews for easier inspection. These controls do not change the saved page size.
All, None, Odd, Even and Select range
Select a group of previews, or enter numbers such as 1,3,5-10 and click Select. These select previews for inspection; Split mode and its page field decide the output sections.
Limits and supported files

PDF documents. A password-protected PDF needs Unlock PDF first.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages. The split tests created two range files, not one file per page.

Split PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

How do I separate pages of a PDF?

Choose your PDF, set Split mode to Every page or Custom ranges, then click Split PDF and download the files or a ZIP.

Does splitting make the pictures less clear?

Splitting keeps the existing image quality and does not use image compression presets. The sizes of the resulting files depend on which pages and shared resources they contain.

Should I split or extract pages?

Use Split PDF when you want separate documents. Use Extract pages when you want selected pages in one new PDF. To discard unwanted pages while keeping the rest, use Remove pages.

Can I split a PDF into equal-sized sections?

Yes. Choose Same number of pages per file in Split mode, then set Pages per file. The last file may have fewer pages.

How do I split a PDF at specific pages?

Choose Split after pages and enter the boundaries, or choose Custom ranges and enter sections such as 1-3,4-6.
