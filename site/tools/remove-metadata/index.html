Remove PDF details help

Remove supported saved PDF details, such as title and author, from a new copy. This helps clean document properties before sharing but does not erase information printed on the pages.

How to use Remove PDF details

  1. Choose the PDF whose saved title, author and other document details you want to clear.
  2. Read the notice: page text, pictures, comments and attachments will stay.
  3. Select Remove details to create a copy without the supported document properties.
  4. Select Download PDF and review the copy before sharing it.
Options explained

Questions

Does removing PDF details make a document anonymous?

No. Names or other identifying information can remain in visible text, pictures, comments and attachments. Review the document itself; use Redact PDF for visible confidential information.

Will the file become much smaller?

Saved details often take up only a small part of a PDF. Removing them may make little difference to file size. Use Compress PDF when reducing images or other document resources is the main goal.

Does removing PDF details change the pages?

The new copy has the supported saved descriptions removed. Visible page content stays unchanged, and there are no image-quality or page-selection settings.

Can removing PDF details invalidate a digital signature?

Yes. Saving an edited PDF changes the signed document. Keep the signed original if its signature must remain verifiable.
