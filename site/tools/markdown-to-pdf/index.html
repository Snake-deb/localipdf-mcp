Markdown to PDF help

Turn Markdown notes, instructions or a report into a PDF with selectable text. Check the live formatting preview while you write, then review the finished PDF before downloading.

How to use Markdown to PDF

  1. Use Open Markdown file or paste Markdown into the editor.
  2. Check the live formatting preview and set File name and the page-layout options.
  3. Select Create PDF and inspect the generated pages; the live preview does not show exact pagination.
  4. Select Download PDF and check headings, tables, lists and code in the saved file.
Options explained
File name
Name the resulting PDF so it is easy to identify after downloading.
Paper size
Choose A4, Letter or A3 to suit the intended printout.
Orientation
Use portrait for Markdown notes or landscape for wider content.
Text size
Increase for easier reading or reduce to fit more text on a page.
Line spacing
Compact, Comfortable or Double changes spacing between lines.
Margins (mm)
Reserve space around the page edges for reading or printing.
Process all files
Choose multiple files to use the settings above on each one. Results and failures appear separately. Use Cancel file, Cancel all files or Download batch as ZIP as needed. Check that page positions or form fields suit every input.
Limits and supported files

Pasted Markdown, .md and .markdown files; external images are not fetched.

Local tests used synthetic 10, 50, 100 and 200 MB Markdown files. Chromium, Firefox and WebKit: none completed; 10, 50, 100, 200 MB did not complete.

Import a Markdown file smaller than 2 MB and use up to 50,000 characters. The Markdown checks used a short formatted document and the 50,000-character boundary; PDF page-count tests do not apply to this input.

Markdown conversion was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Which formatting can I use?

Headings, paragraphs, bold and italic text, lists, quotes, code and simple tables are supported. Web and email links stay clickable. Long tables repeat their header on each new page.

Are pictures and HTML included?

Pictures appear as text labels and HTML appears as plain text. These limitations are shown in the preview. External image files are not fetched.

Will the PDF look exactly like the live preview?

The live preview shows formatting. The PDF uses your chosen paper size, margins and embedded fonts, so line breaks can differ. Use the PDF preview to check the final pages. Latin, Greek and Cyrillic text are supported.

Can I choose the name of the exported PDF?

Yes. Enter a name in File name so the PDF is easy to identify after downloading.
