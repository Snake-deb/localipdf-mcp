PDF Overlay

Add a letterhead, stamp or template PDF over another PDF.

Enable JavaScript in your browser to use this tool.

PDF Overlay help

Place a PDF letterhead, stamp or template over another PDF. Review the combined appearance so the added page does not hide important text or cover the wrong area.

How to use PDF Overlay

  1. Choose your document and a separate PDF to use as the overlay.
  2. Set Template pages and Document pages to choose which content is combined.
  3. Adjust Position, Placement, Size and Visibility, then select Create overlay.
  4. Inspect the combined pages and select Download PDF.
Options explained
Template pages
Repeat one page applies a single template throughout; Use pages in order follows the template sequence.
Template page
Choose which template page to repeat.
Document pages
Select the destination pages that need the template.
Position
Place the overlay relative to the visible page.
Placement
On top of document can cover content; Behind document suits letterheads but may be hidden by opaque page backgrounds.
Edge margin (mm)
Leave space between the overlay and the page edge.
Size
Scale the template to fit the document without changing the document page size.
Visibility
Lower opacity to keep content underneath a foreground template readable.
Create a print copy without a valid digital signature. I’ll keep the signed original.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100, 200 MB. Firefox: completed 10, 50, 100, 200 MB. WebKit: completed 10, 50, 100 MB; 200 MB did not complete. Earlier 200 MB WebKit attempts hit a file-read error; try a smaller document if this happens.

Each overlay input can contain up to 500 pages. Chromium, Firefox and WebKit: completed 50, 300 text pages; 1000 text pages did not complete.

Overlay PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

How is an overlay different from merging PDFs?

An overlay combines visible content on the same page. Merging joins documents one after another. Use a watermark for a repeating text or image mark instead of a whole PDF template.

Can I cover confidential text with an overlay?

An overlay can hide text visually without removing the underlying content. Use Redact PDF when the text must not remain recoverable in the exported document.

Can I repeat a letterhead on every PDF page?

Yes. Choose Repeat one page to apply a single template throughout. Use pages in order follows the template sequence.

Can I use a particular page as the overlay template?

Yes. Use Template page to choose which page to repeat.
