Compress PDF help

Reduce a PDF’s file size before sharing it by email or sending it through a form. Compression runs in your browser and saves a new copy; your original file stays unchanged.

How to use Compress PDF

  1. Choose the PDF you want to make smaller.
  2. For PDFs with images, choose a quality preset or turn on Choose a target file size and enter your limit.
  3. Choose whether to Remove saved document details, then click Compress PDF.
  4. Click Download and check the saved file, especially small print and image detail.
Options explained
Compression preset
Best quality keeps more image detail; Balanced balances size and quality; Strong and Maximum make smaller images. Download the result and check small print before sharing. These options appear for PDFs with images.
Choose a target file size
Try 100 KB, 200 KB, 500 KB, 1 MB, 2 MB or a custom size. If no validated result meets the limit, the tool says so.
Remove saved document details
Clear descriptive properties such as the author when sharing. This does not remove names printed on pages.
Continue and compress
Shown for a digitally signed PDF. Confirm only when you want a changed copy whose digital signature will no longer verify; keep the signed original.

Questions

How do I reduce the file size of a PDF?

Choose your PDF, keep the Balanced preset or set a target size, then click Compress PDF and Download. Image-heavy PDFs usually shrink most; text-only files shrink less.

Which compression option should I choose?

Start with Balanced for everyday sharing. Best quality keeps more image detail; Strong and Maximum favour smaller files. Review small print and fine details before using the result. Image compression can change picture quality, including with Best quality.

Why does a text-only PDF have fewer options?

Image settings do not help a PDF that contains only text and drawings. Those files use the document cleanup and font optimizations available to the compressor. Already compact PDFs may get only slightly smaller.

Can I reduce a PDF to a specific KB or MB limit?

Use a size-target tool such as Compress PDF to 500 KB when an upload form sets a limit. It searches for a smaller copy and tells you if the target was not reached. No preset or target can guarantee that every PDF will fit; long or already compressed documents may need fewer pages.

Is my PDF uploaded during compression?

No. Compression processes the document on your device. Site analytics measure website use, not your PDF contents. Keep the browser tab open until your download is ready.
