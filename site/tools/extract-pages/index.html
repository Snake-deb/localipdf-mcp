Extract pages help

Copy the pages you need into a separate PDF. Extracting is useful when only part of a report, application or reference document needs to be shared.

How to use Extract pages

  1. Choose your PDF and select the page previews you want to keep.
  2. To select several pages at once, enter a range such as 1,3,5-10 in Select range and click Select. Check the highlighted previews before extracting.
  3. Choose Save each selected page as a separate PDF if you need individual files, then click Extract pages.
  4. Click Download for a result, or Download ZIP when several PDFs are ready. Check that the pages you need are included.
Options explained
Select range
Enter pages to keep, such as 1,3,5-10, then click Select to highlight their previews.
Save each selected page as a separate PDF
Enable for one file per selected page; leave off to collect them in one document.
Keep bookmarks
Retain supported navigation for the pages included in the extracted copy.
Make form entries permanent
Shown when a PDF has interactive form fields. Keep the visible answers while making them uneditable in the new file. Digital signatures will no longer verify; keep the signed original.
Jump to page and Thumbnail size
Use Go to locate a page and adjust the size of its preview. These viewing controls do not resize the exported pages.
All, None, Odd, Even and Select range
Select a group of previews, or enter numbers such as 1,3,5-10 in Select range and click Select. None clears the selection; choose pages again before extracting.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

Extract pages was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Are the extracted pages removed from the source?

No. Extraction creates a separate document and leaves the original file unchanged. Open the new file to check that it contains everything you intended to share.

How is extraction different from splitting?

Extraction collects selected pages into a new PDF. Splitting can produce several separate documents. Use Organize PDF if you also need to adjust page order or rotation.

Can I extract pages that are not next to each other?

Yes. Select their previews, or enter a list such as 1,3,5-10 in Select range and click Select. Check that the previews you need are highlighted.

Can I save each selected page as its own PDF?

Yes. Enable Save each selected page as a separate PDF before clicking Extract pages. Leave it off to keep the selected pages together.
