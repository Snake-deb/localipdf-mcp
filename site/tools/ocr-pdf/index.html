OCR PDF help

Recognize words in scanned PDF pages so you can find or copy their text. For photos, create a PDF with Images to PDF or Scan to PDF first. Clear printed pages work better than faded print, complex tables or handwriting; always review important results.

How to use OCR PDF

  1. Choose a scanned PDF and set Pages (leave blank for all).
  2. Choose Text languages and Save as before starting; open More options and click Prepare languages for any that are missing.
  3. Select Recognize text and review the recognized words against the original pages.
  4. Download the result and verify important names, dates and numbers before using it.

Questions

Is recognized text guaranteed to be correct?

No. Similar-looking characters, unusual names, fractions and faint marks can be misread. Check amounts, dates and identifiers carefully. A confidence indicator does not prove that a specific word or number is correct.

Do I need OCR for an ordinary text PDF?

Usually not. If you can already select the words, use PDF to Text, Word or Excel as appropriate. OCR is intended for text stored as pictures, and recognizing it again can introduce errors.

Which file formats can I save recognized text in?

Choose Searchable PDF, Word (.docx), Excel tables (.xlsx), Text (.txt) or Markdown (.md) depending on what you need to edit.

Do I need a password for a PDF that opens normally?

No. PDFs that open without a password are read automatically. If an opening password is required, use Unlock PDF first. Keep signed originals and use an unsigned copy for a searchable PDF.

Can I run OCR on only the scanned pages?

Recognize only selected pages when the rest already has usable text.
