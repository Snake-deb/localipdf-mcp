PDF to PDF/A help

Save each visible page as a picture in a PDF/A-2b archive copy. This is useful when a fixed page appearance matters; it removes selectable text and interactive features. Check the receiving archive’s requirements first.

How to use PDF to PDF/A

  1. Choose a PDF and the picture quality.
  2. Read Good to know. Pages become pictures, so keep your original.
  3. Select Create PDF/A, then check the preview and small print.
  4. Download the copy. Validate it for your archive’s requirements and keep the original.
Options explained
Picture quality
200 DPI or 300 DPI. Higher resolution keeps finer print and creates larger files. Large pages use a lower resolution to fit memory.
Good to know and More
Text, links and comments become pictures; bookmarks, attachments and saved details are not copied.
Limits and supported files

Standard PDFs without switchable layers or XFA. Flatten fillable pages first. Unlock opening-password files first.

128 MB input/output/picture working set. Each rendered page is bounded to 12 megapixels and 8,192 pixels per side.

All pages, up to 100 per PDF. A two-minute deadline and Cancel protect the browser.

Current browsers with local workers. Colour profile and tool assets are included in the initial offline cache.

Each PDF uses the same resolution and picture acknowledgement independently.

Questions

Which PDF/A profile does this create?

PDF/A-2b only. It is a picture-based copy, without searchable text or accessibility tags. It is not PDF/A-2a, PDF/A-2u or PDF/A-4.

Is every download independently validated?

No. We independently test the output design and generated browser outputs with veraPDF. The website does not run a complete ISO validator. For formal submission, validate your downloaded file against the profile your archive requires.

What happens to forms and digital signatures?

Use Flatten PDF first for filled forms. Signed PDFs require acknowledgement: the new copy has no valid digital signature. The original stays unchanged.

Will it be smaller or exactly like the original?

It can be larger. Pictures retain visible page appearance at the chosen resolution, but very fine print, colour management and rendering can differ. Compare the preview before relying on the copy.
