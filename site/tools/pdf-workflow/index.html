PDF Workflow help

Apply a sequence of PDF tasks to your files. Start from a ready-made workflow or build your own, then save the steps for another batch without saving the documents themselves.

How to use PDF Workflow

  1. Choose your PDFs and arrange their order if you plan to combine them.
  2. Under Choose your steps, open Ready-made workflows or choose Action and select Add step for each task.
  3. Review each step and its order, then select Run workflow.
  4. Download individual results or use Download all as ZIP; check the result before applying the saved plan to another batch.
Options explained
Ready-made workflows
Choose a starting sequence and review its steps before applying it to new documents.
Workflow name
Open More options to name and save your steps. Documents and passwords are not saved.
Action and step order
Add actions in the order you want them to run. Combine joins documents; Split creates parts that later steps work on.
Make scanned text searchable and Text languages
Add searchable text to scans without changing their visible pages. Choose the printed languages and review important names and numbers. Extra language data may need a download.
Split by, Pages per file and Separate page ranges
Choose fixed-size sections or explicit ranges for a Split step.
Pages
Choose which pages a supported step applies to.
Turn
Choose the rotation angle for a Rotate step.
Watermark text, Font and Visibility (%)
Set the text mark applied by a Watermark step.
Starting number
Set the initial page label for numbering.
Make form entries permanent
Flatten supported form appearances when combining documents.
Make these part of the page
Choose supported categories in a Flatten step.
Password and Confirm password
Supply the protection password again for each new run; it is not stored in saved plans.
Save workflow and Load workflow
Open More options to save or load reusable steps. Documents and passwords are excluded; review the settings for your next batch.
Cleanup actions
Remove details clears saved descriptions; comments removes added notes and marks; attachments removes embedded files and media; actions disables automatic commands. These do not erase visible text.
Save edited copies. Their digital signatures will no longer be valid.
Shown for signed PDFs. Saving changes invalidates the original digital signature; keep the signed source separately.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100, 200 MB. Firefox: completed 10, 50, 100, 200 MB. WebKit: completed 10, 50, 100 MB; 200 MB did not complete. Earlier 200 MB WebKit attempts hit a file-read error; try a smaller document if this happens.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

PDF workflow was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Can I combine files before applying the steps?

Yes. The optional Combine step puts the PDFs together first. Otherwise, steps can run on separate files. A Split step can create separate outputs, with later steps applied to each resulting part.

Does a saved workflow include my files or passwords?

No. Saved workflows contain the supported step settings, not your PDFs or passwords. Enter protection passwords again when loading a saved plan, and review page ranges for the new documents.

Can I start with a ready-made PDF workflow?

Choose a starting sequence and review its steps before applying it to new documents.

Can I make scanned pages searchable before other steps?

Yes. Add Make scanned text searchable, choose the printed languages, then add steps such as Compress, Watermark or Password. OCR needs an unsigned copy; check recognized names and numbers in the result.

Does page numbering continue across all files?

A numbering step restarts for each separate PDF or split part. Add Combine before numbering if you need one sequence across the whole collection.
