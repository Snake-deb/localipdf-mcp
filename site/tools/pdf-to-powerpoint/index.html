PDF to PowerPoint

Turn PDF pages into picture slides in PowerPoint.

Enable JavaScript in your browser to use this tool.

PDF to PowerPoint help

Turn each selected PDF page into a slide. Page pictures keep appearance; Editable text makes separate text boxes on simple pages, with graphics in the background. Review fonts and layout in PowerPoint.

How to use PDF to PowerPoint

  1. Choose the PDF and enter any page selection in Pages (leave blank for all).
  2. Choose Slide content: Page pictures or Editable text. Then choose Slide size: Match the first selected page or Widescreen (16:9).
  3. Select Convert to PowerPoint. In Editable text mode, check the notice identifying any pages that remain pictures.
  4. Select Download PowerPoint and inspect the slides before presenting.
Options explained
Slide content
Page pictures keeps the visible page together. Editable text creates text boxes on supported simple pages; graphics stay in a picture and uncertain pages use a complete picture. Fonts and spacing can differ.
Pages (leave blank for all)
Select only the PDF pages needed in the presentation.
Slide size
Match the first selected page follows its shape; Widescreen (16:9) suits a typical presentation display. Other page shapes fit without stretching.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

The default Page pictures tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100, 200 MB. Firefox: completed 10, 50, 100 MB; 200 MB did not complete. WebKit: completed 10, 50, 100 MB; 200 MB did not complete. Editable text allows up to two million text characters and 10,000 text boxes per page; these size observations do not measure that mode.

Create slides from up to 200 selected PDF pages at once. Chromium, Firefox and WebKit: completed 50 text pages; 300, 1000 text pages did not complete.

PDF to powerpoint was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Can I edit the words and shapes separately?

Editable text turns simple black text into separate boxes. Graphics remain in a background picture, and fonts may differ. Scanned, rotated, clipped or uncertain pages keep their complete picture. Page pictures keeps everything in one image.

What happens to clickable links and animations?

PDF links, forms and animations do not become PowerPoint controls. Add presentation interactions in PowerPoint afterward. Pages containing forms or comments stay as pictures in Editable text mode.

Can I choose which PDF pages become slides?

Select only the PDF pages needed in the presentation.

Can I make widescreen slides from a PDF?

Match the first selected page follows its shape; Widescreen (16:9) suits a typical presentation display. Other page shapes fit without stretching.
