Redact PDF help

Permanently cover selected areas in a new image-only PDF. The export rebuilds the visible pages so the original text beneath the marked areas is not carried into the new file.

How to use Redact PDF

  1. Choose the PDF and use Add area or draw a box over information to remove.
  2. Use Find text to redact for selectable text if useful, then review every marked area.
  3. Select Preview redactions and review the marked areas. Select Apply redaction, then Confirm redaction in the warning.
  4. Select Download redacted PDF and inspect every page before sharing.
Options explained
Marked areas
Draw and review rectangles over information that must not survive in the new copy.
Find
Search selectable text to suggest areas to cover; scans may not have searchable text and every suggestion needs review.
Confirm redaction
Confirm that you want pages saved as pictures, without the original selectable text or interactive objects.
Save an edited copy. Its digital signature will no longer be valid.
Shown for signed PDFs. Saving changes invalidates the original digital signature; keep the signed source separately.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.

PDF documents. An opening password is required when the file needs one to be read.

Questions

Why does the result lose selectable text?

Each page becomes a new picture with the marked pixels covered. Original text layers, interactive fields and links are not copied. This also means file size can increase and accessibility features are not retained.

Will it automatically find every confidential detail?

No. Search suggestions can help, but you must review all pages and mark everything that should be removed. Unmarked visible information remains readable, including through OCR.

How do I choose information to redact?

Draw and review rectangles over information that must not survive in the new copy.

Can I search for text that needs redacting?

Search selectable text to suggest areas to cover; scans may not have searchable text and every suggestion needs review.
