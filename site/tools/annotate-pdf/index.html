Annotate PDF help

Add text, pictures, notes and drawings to a PDF. Move and style your additions, then check the saved preview. Your original stays unchanged.

How to use Annotate PDF

  1. Choose a PDF to mark up and select its page.
  2. Choose a common mark or open More marks. Enter any text, then drag over the page or use Add at centre.
  3. New text boxes are selected for you. Drag the square handles to resize; text wraps automatically. Use Fit text or Width and Height for more control. Undo and Redo restore changes.
  4. Save your annotated copy. Choose Make new marks permanent only if you do not need to edit them later.
Options explained
Common marks and More marks
Choose a text box, highlight, drawing, rectangle or note. Open More marks for other shapes and pictures.
Page
Switch between pages; marks stay on their original pages.
Fit text, Width and Height
Drag the square handles around a selected text box to resize it. Text wraps and the box keeps enough room for your words. Fit text and Width or Height controls are also available. If the page has no room, move the box or lower Text size.
Make new marks permanent
Paint only your new marks into the page. Existing annotations and form fields are kept.
Font, Text size, Bold, Italic, Underline text, Alignment and Letter spacing
Text size stays beside your text. Open More options for font, style, alignment, spacing, visibility and rotation. Text must fit its box; check the saved preview.
Picture
Insert a PNG, JPG or WebP, then move, resize, rotate, crop or replace it. Cropping hides edges without removing the original pixels from the file.
Replace visually
After your confirmation, place a coloured cover and new text over the page. The original words remain in the file. This is not secure redaction. Use Edit PDF for supported direct text changes or Redact PDF to remove private information.
Process all files
Choose multiple files to use the settings above on each one. Results and failures appear separately. Use Cancel file, Cancel all files or Download batch as ZIP as needed. Check that page positions or form fields suit every input.
Limits and supported files

PDF files that can be opened without a password. Use Unlock PDF first when necessary.

Up to 500 new marks per copy and 2,000 characters in each text box or note. Inserted pictures are limited to 16 million pixels, an 8,192-pixel edge and 12 MB after conversion to PNG; use fewer or smaller pictures if the combined picture budget is exceeded.

Local tests saved a note on the last page of PDFs with 50, 300 and 1,000 simple text pages. Text boxes that would cut off text are rejected on save.

All seven capacity tests passed in Chromium, Firefox and WebKit, including a 200 MB generated image PDF. Your file may need more memory; mobile devices and the Safari app were not tested.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Can I edit saved PDF annotations in another reader?

Your marks are saved as editable PDF comments. Editing support varies by reader and mark type. Flattened marks become part of the page and cannot be edited separately.

Does adding a text box replace the original words?

No. A text box adds a visible mark over the page. Use Redact PDF to permanently remove sensitive page content.

Which kinds of PDF marks are available?

Text boxes, pictures, highlights, underlines, strike-through marks, freehand drawings, rectangles, ovals, lines, arrows, polygons, sticky notes and callouts. Drag to place a mark.

What happens to a signature when I annotate a PDF?

Changing a digitally signed file prevents its original signature from verifying. The tool requires confirmation before creating an edited copy. Keep the signed original.
