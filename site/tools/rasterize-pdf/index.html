Rasterize PDF

Turn PDF pages into pictures inside a new PDF.

Enable JavaScript in your browser to use this tool.

Rasterize PDF help

Rasterize PDF replaces selected pages' visible text, graphics and marks with pictures. Other pages stay unchanged. This can help with fixed page appearance; it is not compression or secure data removal.

How to use Rasterize PDF

  1. Choose a PDF and the pages to convert, or leave the range empty for all.
  2. Choose the picture resolution.
  3. Click Turn pages into pictures and compare the result with the original.
  4. Download the new PDF and keep the original.
Options explained
Pages (leave blank for all)
Convert all pages or selected ranges. Pages you leave out keep their original content.
Picture quality
72, 144, 200 or 300 DPI. Higher values create larger pictures; unusually large pages are bounded to fit memory.
Limits and supported files

Standard PDFs without switchable layers or XFA. Selected fillable pages need Flatten PDF first.

128 MB input/output/converted-picture working set. Rendering is bounded to 12 megapixels and 8,192 pixels per side.

Up to 500 source pages; select up to 100 per run. A two-minute deadline and Cancel protect the browser.

Current browsers with local workers. Included in the initial offline cache.

Each PDF uses the same page range and resolution independently.

Questions

Can I select text afterwards?

Not on converted pages. Links and comments are no longer interactive there; accessibility tags are removed from the whole new copy.

Are hidden contents securely removed?

No. Rasterize PDF is an appearance tool. Saved document details and unused hidden objects may remain. Use Redact PDF for confidential content.

What about forms, bookmarks and signatures?

Flatten fillable pages before converting them. Local bookmarks retain their page destinations. A changed copy invalidates digital signatures and requires acknowledgement.

Can the file become larger?

Yes. Page pictures can be much larger than native text. This tool does not promise compression.
