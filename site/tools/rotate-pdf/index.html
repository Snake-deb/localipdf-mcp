Rotate PDF

Turn individual pages or your entire document around.

Enable JavaScript in your browser to use this tool.

Rotate PDF help

Fix sideways or upside-down PDF pages using the rotation controls on their previews. Save the orientation in a new PDF instead of only changing how a viewer displays it.

How to use Rotate PDF

  1. Choose your PDF and select the page previews that need turning. Use All to select every page.
  2. Click Rotate once for a quarter turn clockwise, twice for a half turn. Use Undo to correct a mistake.
  3. Check the previews, then click Save rotated PDF.
  4. Click Download and open the saved PDF to check the page directions.
Options explained
Page selection
Select the previews of the pages that need turning; leave correctly oriented pages unselected.
Rotate
Each click turns the selected pages 90 degrees clockwise. Click twice for upside-down pages.
Undo and Redo
Reverse a rotation or restore an undone turn before creating the PDF.
Jump to page and Thumbnail size
Use Go to locate a page and adjust the size of its preview. These viewing controls do not resize the exported pages.
All, None, Odd, Even and Select range
Select a group of previews, or enter numbers such as 1,3,5-10 and click Select. Choose which pages Rotate will turn.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

Rotate PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Can I rotate just one page?

Yes. Select only that page preview, then click Rotate. Other pages keep their orientation. Check the preview before clicking Save rotated PDF.

Does rotation compress or crop the page?

Rotation changes orientation. It does not apply image compression or trim page margins. Use Compress PDF to reduce file size, or Crop PDF to change the visible page area.

How do I rotate all pages at once?

Use Rotate all left or Rotate all right. Each click turns every page a quarter turn; no selection is needed.

Can I undo a rotation before saving?

Yes. Click Undo to reverse the last change. Check the previews before clicking Save rotated PDF.
