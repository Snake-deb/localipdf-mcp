Page numbers

Add page numbers to your PDF and choose where they appear.

Enable JavaScript in your browser to use this tool.

Page numbers help

Add page numbers to make your PDF easier to reference. Choose the numbering settings, then check that the numbers do not cover existing content.

How to use Page numbers

  1. Choose your PDF, then set the starting number and position.
  2. Open More options to change the format, text style or which pages to skip.
  3. Check the preview. Use Choose pages to number only some pages, then click Add page numbers.
  4. Click Download and check the first and last numbered pages for the right sequence and placement.
Options explained
Choose pages
Number all pages, or open Choose pages to select the ones you want.
Number format
Use a plain number, Page 1-style label or a current/total count.
Starting number and Starting page
Set the first label and the first eligible source page.
Skip first pages
Skip front matter such as a cover; numbering starts after any excluded pages.
Numbering sequence
Choose Keep original page-number gaps to follow the original page positions. Choose Count only numbered pages for consecutive numbers on the selected pages.
Total page count
For the current/total format, choose all source pages or only numbered pages.
Minimum digits, Prefix and Suffix
Pad numbers with zeros or add text before and after each number.
Font, Text size and Color
Match the added labels to the document without changing existing text.
Visibility, Position and Margin (mm)
Control visibility and placement so numbers do not overlap existing content.
Preview before export
Switch between With current settings, Original and Side by side to check the placement before exporting.
Start live preview
Smaller PDFs preview automatically. Use Start live preview for larger files, or Pause while editing. Zoom affects only the preview.
Jump to page and Thumbnail size
Use Go to locate a page and adjust the size of its preview. These viewing controls do not resize the exported pages.
All, None, Odd, Even and Select range
Open Choose pages and select thumbnails, use a shortcut, or enter numbers such as 1,3,5-10 and click Select.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

Page numbers was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Can I number several documents in one sequence?

Use Bates Numbering when the sequence must continue across separate PDFs. Ordinary page numbers are useful for one document; Bates numbering helps identify pages across a document collection.

What if my PDF already has printed page numbers?

New numbers are added to the visible page; existing printed numbers are not automatically replaced. Choose a clear position and review the first and last pages to avoid conflicting labels.

How do I leave the cover page unnumbered?

Open More options and set Skip first pages to 1. Check Starting number and Numbering sequence to choose how numbering continues after the cover.

Can I add page numbers with a total page count?

Yes. In More options, choose 1 / 50 in Number format. Total page count lets you use the whole document or only the numbered pages.
