PDF to HTML

Create a webpage with PDF page pictures or selectable text.

Enable JavaScript in your browser to use this tool.

PDF to HTML help

Save your PDF as one webpage. Page pictures keep its appearance; Formatted text turns clear headings, lists and simple tables into webpage elements. Preview the result before downloading.

How to use PDF to HTML

  1. Choose the PDF and set Pages to include the sections you need.
  2. Choose Page pictures, Text only or Formatted text. For Page pictures, decide whether to include selectable text below each page.
  3. Select Create HTML and inspect Preview page to check the conversion.
  4. Select Download HTML and open the self-contained file in a browser.
Options explained
Pages (leave blank for all)
Choose the PDF pages to include in the saved webpage.
Page layout
Page pictures keep appearance, Text only copies words, and Formatted text detects clear headings, lists and simple tables.
Join wrapped lines
In Formatted text, join clearly related lines into paragraphs. Leave this off if you need to keep the line breaks.
Include selectable text below each page
Add extracted words below page pictures to make copying easier; review reading order.
Preview page
Inspect each converted page before downloading the HTML file.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100 MB; 200 MB did not complete. Firefox: completed 10, 50 MB; 100, 200 MB did not complete. WebKit: completed 10, 50 MB; 100, 200 MB did not complete.

Export up to 200 selected PDF pages into one HTML file. Chromium, Firefox and WebKit: completed 50 text pages; 300, 1000 text pages did not complete.

PDF to HTML was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Is the PDF rebuilt as editable webpage elements?

Formatted text creates headings, lists, paragraphs and simple table cells when it can identify them clearly. It does not copy the exact page design or pictures. Use Page pictures to keep the appearance, or Text only when the layout is uncertain.

Does the downloaded webpage contact an external service?

The downloaded file has no scripts, analytics or remote assets. Pictures, when selected, are included in the file. The localiPDF website has its own analytics disclosure in the privacy policy.

Can I turn selected PDF pages into a webpage?

Choose the PDF pages to include in the saved webpage.

Can the HTML file keep the PDF page appearance?

Page pictures keep appearance. Text only and Formatted text create lighter results from selectable words; neither reproduces the exact PDF design.

What happens to scans or unusual tables?

Scanned pages without selectable text are marked as having no text; OCR is not run automatically. Clear numeric tables can keep rows and columns, including tables without a header. Merged tables and unusual columns may need arranging. Rotated or uncertain reading order stays as plain text with a warning.
