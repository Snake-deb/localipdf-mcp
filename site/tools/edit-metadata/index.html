Edit PDF details

Change a PDF’s title, author and other details.

Enable JavaScript in your browser to use this tool.

Edit PDF details help

Change saved PDF details such as the title and author. These properties describe the file and are separate from the visible text printed on its pages.

How to use Edit PDF details

  1. Choose the PDF and read its current document details.
  2. Change Title, Author or the other fields you need; leave a field blank to remove it.
  3. Select Save details to create the updated copy.
  4. Select Download PDF and check the saved properties in your PDF reader.
Options explained
Title and Subject
Edit the document description shown in PDF properties, without changing text on the page.
Author and Keywords
Update attribution and search keywords stored with the document.
Created with and PDF software
Edit the saved application names when correcting document properties.
Date created and Date modified
Edit the saved dates; these are document properties, not verified timestamps.
Leaving a field blank
Clear a field to remove its saved value. Dates use YYYY-MM-DD, such as 2026-09-30; these are editable properties, not certified timestamps.
Save an edited copy. Its digital signature will no longer be valid.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Process all files
Choose multiple files to use the settings above on each one. Results and failures appear separately. Use Cancel file, Cancel all files or Download batch as ZIP as needed. Check that page positions or form fields suit every input.

Questions

Does changing the author change a name on the page?

No. Document properties and visible page content are separate. Editing the saved author does not replace a name printed in the PDF or remove comments that mention that person.

How do I remove saved details instead?

Use Remove PDF details to clear supported saved details. For broader cleanup, such as comments, attachments and automatic actions, use Clean PDF and review the categories selected for removal.

Can I remove a saved date without changing the page?

Yes. Clear Date created or Date modified and select Save details. Blank fields remove the corresponding property; printed dates stay unchanged.

Can I change the author saved in a PDF?

Yes. Edit Author and select Save details. You can also update the search keywords stored with the document.
