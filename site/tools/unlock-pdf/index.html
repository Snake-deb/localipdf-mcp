Remove password protection from a PDF you can access.

Enable JavaScript in your browser to use this tool.

Unlock PDF help

Remove password protection from a PDF you can access and download an unlocked copy. Files that open without a password are handled directly. If the PDF requires a password to open, you still need to enter it.

How to use Unlock PDF

  1. Choose the protected PDF you have permission to edit.
  2. Enter PDF password if the document needs one to open; files that open without it are handled automatically.
  3. Select "I have permission to unlock these PDFs." Then click Unlock PDF.
  4. Select Download and check that the unlocked copy opens as expected.
Options explained
PDF password
Enter the opening password only when required. A file that opens with an empty password is handled automatically.
I have permission to unlock these PDFs.
Confirm that you have permission to remove protection before saving an unlocked copy.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

Unlock PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

Why can some PDFs unlock without a password?

Some PDFs restrict editing or printing but allow anyone to open them. When the document can be opened without a password, localiPDF can process it without asking you to enter one.

Can it unlock a PDF whose opening password I do not know?

No. If a password is required to read the file, you need that password. The tool does not guess or crack it. Use documents you are authorized to access and modify.

Do I need a password if the PDF opens without one?

Enter the opening password only when required. A file that opens with an empty password is handled automatically.

Can I unlock a document that belongs to someone else?

Only unlock documents you have permission to use. Select the checkbox labeled "I have permission to unlock these PDFs." before saving an unlocked copy.
