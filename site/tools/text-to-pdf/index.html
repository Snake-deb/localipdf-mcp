Text to PDF help

Turn pasted text or a text file into a PDF with selectable words. Choose page size, orientation, margins and text settings to prepare a simple document for sharing or printing.

How to use Text to PDF

  1. Use Open text file or paste your words into Text.
  2. Set File name, Paper size, Orientation, Text size, Margins (mm) and Line spacing.
  3. Select Create PDF and review the generated page preview.
  4. Select Download PDF and check the saved text and page breaks.
Options explained
File name
Name the resulting PDF so it is easy to identify after downloading.
Paper size
Choose A4, Letter or A3 to suit the intended printout.
Orientation
Use portrait for ordinary reading or landscape for wider content.
Text size
Increase for easier reading or reduce to fit more text on a page.
Line spacing
Compact, Comfortable or Double changes spacing between lines.
Margins (mm)
Reserve space around the page edges for reading or printing.
Process all files
Apply these settings to several text files. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.
Limits and supported files

Pasted text or plain-text files; not Word documents.

Local tests used synthetic 10, 50, 100 and 200 MB plain-text files. Chromium, Firefox and WebKit: none completed; 10, 50, 100, 200 MB did not complete.

Import a text file smaller than 2 MB and use up to 200,000 characters; the generated PDF can contain up to 500 pages. Chromium, Firefox and WebKit: completed 50, 300 text pages; 1000 text pages did not complete.

Text conversion was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Can I use this to convert a Word document?

This tool accepts plain text, not a Word document with its original formatting. Paste the words you need and choose a new layout. Pictures, complex tables and Word styling are not imported as a document design.

Does it support every writing system?

No. Supported Latin, Greek and Cyrillic characters can be exported with embedded fonts. The tool reports unsupported characters rather than silently replacing them. Check the preview if your text includes symbols or other scripts.

Can I choose the downloaded PDF filename?

Name the resulting PDF so it is easy to identify after downloading.

Can I format my text for A4, Letter or A3 paper?

Choose A4, Letter or A3 to suit the intended printout.
