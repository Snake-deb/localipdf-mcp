Merge PDF

Combine several PDFs into one file, in the order you choose.

Enable JavaScript in your browser to use this tool.

Merge PDF help

Combine several PDFs into one document in the order you choose. This is useful for sending an application, collecting invoices or keeping a report and its attachments together.

How to use Merge PDF

  1. Choose the PDFs or supported images you want to combine.
  2. Drag files or page previews into order. To move selected pages precisely, enter Move to page and click Move.
  3. Choose Keep bookmarks or Add a bookmark for each file if you want navigation in the combined document.
  4. Click Merge PDFs, then Download. Open the result to check the page order.
Options explained
Keep bookmarks
Retain supported bookmarks for included pages and their groups when combining documents.
Add a bookmark for each file
Create a navigation entry for each source document; useful for a bundle with several attachments.
File and page order
Drag files or pages into the desired order; selected pages can move together.
Blank page size, Size unit, Blank page width and Blank page height
Choose a standard page size or custom dimensions in millimeters, inches or points.
Blank page background
Choose the color of a newly inserted blank page.
Insert position and Reference page
Place a blank page before or after an existing page.
Blank page orientation
Choose portrait or landscape for an inserted blank page. This does not rotate existing pages.
Make form entries permanent
Shown when a PDF has interactive form fields. Keep the visible answers while making them uneditable in the new file. Digital signatures will no longer verify; keep the signed original.
Undo and Redo
Step backward or forward through workspace changes before saving. Your original PDF is not overwritten.
Jump to page and Thumbnail size
Use Go to find a page preview, or resize the previews for easier inspection. These controls do not change the saved page size.
All, None, Odd, Even and Select range
Select a group of page previews quickly. Enter page numbers in Select range and click Select, then check the highlighted pages before applying changes.
Rotate, Duplicate and Remove
Turn, copy or discard selected pages before merging. Use Undo to correct a change.
Move to page, First and Last
Place selected pages at a numbered position, at the start or at the end of the combined document.
Limits and supported files

PDF documents and JPG, PNG or WebP images. A password-protected PDF needs Unlock PDF first.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages. Each test added one companion PDF; this does not measure large batches of separate files.

Merge PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Questions

How do I combine PDF files into one?

Choose your PDFs, drag them into order, then click Merge PDFs and Download. The files are combined on your device, not uploaded.

Can I rearrange individual pages while merging PDFs?

Yes. Drag the page previews or select a group and use Move to page. You can also open the saved result in Organize PDF to make more changes.

What happens to filled forms and signatures?

A file with interactive forms may need its filled values made part of the page before merging. Read the warning before continuing. Editing a digitally signed PDF changes the signed document, so keep the original for signature verification.

Will my merged PDF keep its bookmarks?

Enable Keep bookmarks to retain supported entries for included pages and their groups. Links to omitted pages are dropped.

Can I add a bookmark for each document?

Yes. Enable Add a bookmark for each file to give each source document a navigation entry in the merged PDF.
