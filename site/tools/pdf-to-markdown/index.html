PDF to Markdown help

Save selectable PDF text as a Markdown file for notes or another writing tool. Clear headings, lists and simple tables keep their structure. Check the preview before downloading.

How to use PDF to Markdown

  1. Choose your PDF and leave Pages blank, or enter a page selection.
  2. Select Convert to Markdown and check each preview page.
  3. If needed, turn on Join wrapped lines and convert again. Include page labels when you want to keep track of the source pages.
  4. Select Download Markdown. You can also copy a preview page or continue with Markdown to PDF.

Limits and supported files

PDFs with selectable text. Use Unlock PDF first if a password is required to open the document.

PDFs up to 256 MB. Up to two million text characters across a selection; choose fewer pages for larger text documents.

Up to 200 selected pages per conversion. Detection is conservative: merged tables, complex columns and uncertain reading order may need arranging.

Tests cover Chromium, Firefox and WebKit on a Mac. WebKit is not a physical Safari or mobile-device check.

One Markdown file per PDF. Unsupported files are reported individually; other valid files continue.

Questions

Does this work with scanned PDFs?

This reads existing selectable text. A picture of a page has no text to copy; those pages are listed so you can open the file in OCR if needed. OCR is not run automatically.

How are headings and tables found?

Large bold text can become headings. Explicit bullet marks become lists. Repeated aligned rows with numbers can become simple tables. Uncertain layouts stay as text; review columns and unusual page layouts.

Will pictures and links be copied?

Pictures and the original page layout are not copied. Text that looks like HTML or Markdown is kept as literal text. Links are not reconstructed from PDF annotations.

What happens to tables without a heading?

Every data row is kept. Markdown requires a header line, so the converter adds an empty one if it cannot find a clear header. It does not invent column names.
