Pages per sheet

Fit 2, 4, 6, 8, 9 or 16 PDF pages on each sheet for printing.

Enable JavaScript in your browser to use this tool.

Pages per sheet help

Fit multiple PDF pages onto each sheet for compact handouts or fewer printed sheets. Choose a layout and check that the smaller text is still readable before printing.

How to use Pages per sheet

  1. Choose the source PDF for your handout.
  2. Select Pages on each sheet, Paper size and Orientation.
  3. Set Pages and Page order, then select Create sheets to inspect the result.
  4. Select Download PDF and print with one output sheet per printed page.
Options explained
Pages on each sheet
Choose how many pages to place on each sheet. A higher count makes each page smaller.
Paper size
Choose A4, A3, Letter or Custom for the output sheet.
Orientation
Use portrait or landscape to suit the arrangement.
Sheet width (mm) and Sheet height (mm)
Set custom paper dimensions when standard sizes do not fit.
Page order
Set the reading order to Across, then down; Down, then across; or Right to left.
Pages (leave blank for all)
Choose the source pages to place on the sheets.
Outer margin (mm)
Keep content away from the physical sheet edge.
Space between pages (mm)
Leave space between pages to make them easier to read.
Add a thin border around each page
Draw an outline to make individual pages easier to distinguish.
Create a print copy without a valid digital signature. I’ll keep the signed original.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100, 200 MB. Firefox: completed 10, 50, 100, 200 MB. WebKit: completed 10, 50, 100 MB; 200 MB did not complete. Earlier 200 MB WebKit attempts hit a file-read error; try a smaller document if this happens.

The sheet-layout tool accepts documents with up to 500 pages. Chromium, Firefox and WebKit: completed 50, 300 text pages; 1000 text pages did not complete.

Pages per sheet was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Will small print still be readable?

Placing more pages on a sheet makes each original page smaller. Check the preview and print a sample when readability matters. Fewer pages per sheet leave more room for text and diagrams.

Should I also select multiple pages per sheet in my printer?

The downloaded PDF already has the selected layout. Printing it with another multiple-pages-per-sheet setting reduces it again. Check your print preview and paper size to avoid an unintended second reduction.

How do I fit more PDF pages on one printed sheet?

Choose how many pages to place on each sheet. A higher count makes each page smaller.

Can I choose the output paper size?

Choose A4, A3, Letter or Custom for the output sheet.
