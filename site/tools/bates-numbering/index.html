Bates Numbering

Add unique page numbers that continue across your PDFs.

Enable JavaScript in your browser to use this tool.

Bates Numbering help

Add page identifiers that continue across several PDFs. Arrange the documents first so the sequence follows the order you need for a document bundle.

How to use Bates Numbering

  1. Choose your PDFs and use the file-order controls to arrange the collection.
  2. Set Starting number and Prefix. Open More options for leading zeros, a suffix and text formatting.
  3. Check Position and the live preview, then click Add Bates numbers to number the documents in sequence.
  4. Select Download for each result or Download ZIP for the collection; check the first and last labels.
Options explained
File order

Starting number
Set the first identifier in the collection.
Minimum digits
Pad short numbers with leading zeros for labels of a consistent width.
Prefix and Suffix
Add a case code or other short text before or after each number.

Questions

How is this different from ordinary page numbers?

Bates numbering continues a sequence across separate documents so each page in the collection has its own identifier. Ordinary numbering is usually used to label pages within one PDF.

Should I finish rearranging pages before numbering?

Yes. Finalize the document and page order first, then add identifiers. If you change the order later, review the sequence again so the labels still match the collection you intend to share.

Can I number multiple PDFs in a chosen order?

Yes. Arrange the documents before numbering. The sequence continues across every page while the files stay separate.

Can Bates numbering start from a number other than one?

Yes. Enter the first number you need in Starting number.
