Flatten PDF help

Make supported filled forms, comments or stamps part of the printed page. Choose which categories to flatten while keeping a separate original if you need to edit them later.

How to use Flatten PDF

  1. Choose a PDF with filled forms, comments or stamps.
  2. Select Form fields, Comments and marks, or Signatures and stamps to choose what becomes permanent page content.
  3. Select Flatten PDF; keep your original if you may need to edit these items later.
  4. Select Download flattened PDF and check that the answers and marks appear correctly.
Options explained
Form fields
Make supported filled-field appearances part of the page when the answers no longer need to be interactive.
Comments and marks
Flatten supported annotations into the page while preserving their visible appearance.
Signatures and stamps
Keep supported visible marks as page content; this does not preserve cryptographic signature validity.
Save an edited copy. Its digital signature will no longer be valid.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Process all files
Choose multiple files to use the settings above on each one. Results and failures appear separately. Use Cancel file, Cancel all files or Download batch as ZIP as needed. Check that page positions or form fields suit every input.

Questions

Does flattening make a PDF impossible to edit?

No. It removes the selected interactive items and places their saved appearance on the page. Other PDF editing may still change page content. It is not encryption or permanent redaction.

Will a digital signature remain valid?

Editing a signed PDF changes the signed document. Flattening may keep a signature’s visible appearance, but it does not preserve its cryptographic validity. Retain the signed original when signature verification matters.

Can I make filled form answers permanent?

Yes. Select Form fields to make supported filled-field appearances part of the page when the answers no longer need to be interactive.

Can I keep comments visible after flattening?

Yes. Select Comments and marks to make supported annotations part of the page while keeping their visible appearance.
