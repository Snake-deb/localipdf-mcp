Word to PDF

Turn a Word document into a PDF, with its pictures and tables.

Enable JavaScript in your browser to use this tool.

Word to PDF help

Open a Word document (.docx), check the preview, then save it as a PDF from your browser's print window. Pictures, tables, lists and page breaks are kept, along with text in any language your device has fonts for. Your file stays on this device.

How to use Word to PDF

  1. Select Choose files and pick your .docx document.
  2. Read through the preview. Look at pictures, tables and where each page ends.
  3. Select Save as PDF. Your browser's print window opens.
  4. Choose Save as PDF as the printer (on an iPhone, use Share, then Save to Files) and save.
Options explained
Preview
Shows your document as it will print. Text stays selectable in the PDF.
Save as PDF
Opens your browser's print window with the paper size and margins from your Word file.
Add files
Opens another .docx file. It replaces the current preview.
Limits and supported files

Word documents saved as .docx. Older .doc files and password-protected documents are not opened.

Up to 50 MB per file. Very long documents with many pictures can be slow on phones.

No set page limit. Page breaks follow your document, and long sections flow onto new pages with the same margins. Where a page ends can differ from Word.

Tested in Chromium, Firefox and WebKit on a Mac. The print window looks different in each browser. Firefox may add its own headers and footers unless you turn them off.

One document at a time.

Questions

Will the PDF look exactly like it does in Word?

It comes close, but it isn't always exact. Fonts that aren't on this device are swapped for similar ones, so lines and page breaks can move. Check the preview first. If the layout must match Word exactly, use Save as PDF inside Word.

Are Hindi, Tamil and other Indian-language documents supported?

Yes, when the text is typed in Unicode, which current versions of Word use. Your device's own fonts draw the letters. Older documents typed in fonts such as Kruti Dev only look right if that font is installed.

Why does my PDF show a web address or date?

Your browser added them. In the print window, open More settings and turn off Headers and footers, then save again.

Can I convert .doc files or password-protected documents?

No. Open the file in Word, save it as .docx without a password, then choose it here.

What is left out of the PDF?

Charts, SmartArt, equations and some drawn shapes may be missing or simplified. Comments and tracked changes are not shown. Headers and footers appear once per section, not on every page, and page numbers may be missing.

Is my document uploaded?

No. Your browser reads the file and makes the PDF on this device. Nothing is uploaded, so there is nothing to delete later. You can check it at /verify/.
