HTML to PDF

Turn HTML text, headings, lists and simple tables into a PDF.

Enable JavaScript in your browser to use this tool.

HTML to PDF help

Make a readable PDF from an HTML file or pasted HTML. Text stays selectable, and you can choose the paper size, text size and margins.

How to use HTML to PDF

  1. Open an HTML file or paste HTML into the editor.
  2. Check the live preview and choose your page layout.
  3. Select Create PDF and review the finished pages.
  4. Select Download PDF to save your file.
Options explained
File name
Choose a name for the downloaded PDF.
Paper size
Choose A4, Letter or A3.
Orientation
Choose portrait or landscape.
Text size
Make the text larger or fit more text on each page.
Line spacing
Choose Compact, Comfortable or Double.
Margins (mm)
Choose how much space to leave around the page.
Process all files
Create one PDF for each selected HTML file.
Limits and supported files

.html, .htm and .xhtml files or pasted HTML. Website styling, scripts and pictures are not copied.

Import a file up to 2 MB and use up to 50,000 HTML characters at a time.

Up to 500 generated pages. Simple tables support up to 12 columns; oversized rows and merged cells need to be simplified first.

Tested in Chromium, Firefox and WebKit on a Mac. WebKit tests do not replace a check in Safari or on your own phone.

One PDF per selected source file, using the chosen page layout. Edits in the preview apply to the single-file export.

Questions

Does this copy a website exactly?

No. This creates a document from headings, text, lists, quotes, code and simple tables. Website styles, scripts, forms and embedded content are left out. Pictures appear as labels. Check the preview before downloading.

Can I convert a website address?

Open a saved .html or .htm file, or paste HTML. Website addresses and external picture files are not opened or downloaded. Full web and email links in the text stay clickable.

Which tables and languages are supported?

Use rectangular tables with up to 12 columns and no merged cells. A single header row repeats on each new page. Latin, Greek and Cyrillic text are supported.

Are my files uploaded?

No. Importing, previewing and converting happen in your browser. Your HTML and PDF are not sent to a server.
