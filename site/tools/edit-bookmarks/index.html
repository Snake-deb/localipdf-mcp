PDF Bookmarks

Add and organize shortcuts to pages in your PDF.

Enable JavaScript in your browser to use this tool.

PDF Bookmarks help

Add and organize PDF bookmarks so readers can jump to important pages. Use a hierarchy of headings for chapters, sections or supporting documents.

How to use PDF Bookmarks

  1. Choose your PDF and inspect its current bookmark list.
  2. Select Add bookmark, enter Bookmark title and choose Destination and Destination page.
  3. Use Place under and Move up or Move down to arrange the list, then select Save bookmarks.
  4. Select Download PDF and test the navigation in your reader.
Options explained
Bookmark title
Enter the navigation label readers will see.
Destination
Choose Go to a page, Heading only, or Keep existing link when an existing destination is supported.
Destination page
Set the page to open when the bookmark is clicked.
Place under
Nest a bookmark under another heading or choose Top level.
Show children when the PDF opens
Expand a bookmark group initially in compatible readers.
Suggest headings
Use detected headings as starting points, then review their titles and destinations.
Add bookmark and Delete
Create a navigation entry or remove it. Deleting a parent also deletes its children.
Move up and Move down
Reorder an entry among others under the same parent.
Undo and Redo
Restore or repeat bookmark edits before saving.

Questions

Do bookmarks add a contents page?

Bookmarks are navigation entries displayed by compatible PDF readers. They do not automatically add a printed table of contents to the document’s pages.

What happens if I later remove a bookmarked page?

Page-editing tools can omit destinations that no longer exist. A heading can remain when it still has retained child bookmarks. Review navigation after major changes to page order or selection.

Can I rename PDF bookmarks?

Yes. Change Bookmark title to the label you want readers to see.

Can I create a bookmark heading without a page link?

Yes. Choose Heading only under Destination. Go to a page adds a page link; Keep existing link preserves a supported existing destination.
