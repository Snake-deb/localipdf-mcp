Clean PDF help

Clean selected types of extra content from a PDF, including comments, attached files, scripts and saved information. Choose the categories you need and keep the original separately.

How to use Clean PDF

  1. Choose the PDF you want to clean.
  2. Use Recommended cleanup, or open Customize cleanup to choose what to remove.
  3. Select Clean PDF after checking that you are keeping any comments, links and form answers you still need.
  4. Select Download cleaned PDF and review the pages and remaining document information.
Options explained
Document details
Choose saved Title, Author, Subject, Keywords, Created with, PDF software, Date created and Date modified properties to remove.
Other saved details
Remove extra properties saved by the software that created the PDF.
Hidden document details
Remove hidden descriptions saved in the PDF; camera details inside photos are not removed.
Comments and markup
Remove notes, highlights, drawings and stamps.
All comments, marks and links
Remove annotations and links while keeping fillable form fields.
Attached files and media
Remove file attachments, audio, video and 3D objects.
Automatic actions
Remove commands or links that run automatically.
Filled-in form answers
Clear current and default answers, including signature fields; also disable automatic actions.
Select all and Clear selection
Select all also includes links and filled-in answers. Clear selection lets you choose just the information you want removed.
Save an edited copy. Its digital signature will no longer be valid.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.

Questions

Does cleanup remove confidential text on a page?

No. Cleaning document extras is different from redacting visible content. Names, numbers and pictures on the page can remain. Use Redact PDF for information that must not be readable in the result.

Is a cleaned file guaranteed safe?

No. The tool removes the supported categories you select. It does not scan for malware or check every security risk in a document.

Which saved document details can I remove?

Choose saved Title, Author, Subject, Keywords, Created with, PDF software, Date created and Date modified properties to remove.

Can I remove extra properties added by other software?

Remove extra properties saved by the software that created the PDF.
