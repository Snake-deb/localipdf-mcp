PDF Forms help

Fill supported PDF form fields or create a form of your own. Review the completed document before saving so names, dates, checkboxes and other values are correct.

How to use PDF Forms

  1. Choose a PDF form, or select Create a blank form to start a new one.
  2. Use Fill to enter answers. In Design, choose Field type, select Add field and adjust its name, size and position.
  3. Check the answers and field tab order, then select Save form PDF.
  4. Select Download saved form and reopen it to verify the fields and values.
Options explained
Form mode
Fill existing fields or use Design mode to create and arrange supported fields.
Field type
Choose the kind of input before adding it to the page.
Field name and Help text
Name each field and add instructions for the person filling it in.
Required and Read-only
Mark necessary answers or prevent ordinary editing of a field in compatible readers.
Value, Selected value and Checked
Enter the answer using the control for that type of field.
Default value, Default choice and Checked by default
Set the starting answer for a field.
Choices (one per line)
Enter the options for a choice field, one per line.
Font, Text size (0 for automatic) and Text color
Adjust the appearance of supported text fields.
Character limit (0 for no limit)
Limit the length of an answer when a field has a fixed format.
Left (pt), Top (pt), Width (pt) and Height (pt)
Position and size the field on the page.
Field tab order
Move fields earlier or later to control keyboard navigation.
Duplicate field
Create another field from the selected one and review its name and position.
Delete field
Remove the selected field from the form design. Undo restores a mistaken deletion.
Undo and Redo
Step back or forward through changes to the form design.
Save an edited copy. Its digital signature will no longer be valid.
Shown for signed PDFs. Saving changes invalidates the original digital signature; keep the signed source separately.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium, Firefox and WebKit: completed 10, 50, 100, 200 MB.

Chromium, Firefox and WebKit: completed 50, 300, 1000 text pages.

PDF forms was tested on a 16 GB Mac with Chromium, Firefox and WebKit. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

How do I save filled PDF fields as non-interactive content?

Flatten PDF can turn supported saved field appearances into ordinary page content. Keep an editable original if you may need to change the answers later. Flattening is not a guarantee against other PDF editing.

Does every kind of PDF form work?

No. Some forms use unsupported features or have missing saved appearances. Follow the tool’s message for the affected file and check the downloaded result in a PDF reader.

Can I fill an existing form or make a new one?

Fill existing fields or use Design mode to create and arrange supported fields.

Can I choose different types of form fields?

Choose the kind of input before adding it to the page.
