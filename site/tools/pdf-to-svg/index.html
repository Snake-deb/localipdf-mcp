PDF to SVG

Save PDF pages as SVG images, with editable text where possible.

Enable JavaScript in your browser to use this tool.

PDF to SVG help

Create one SVG image for each selected PDF page. Simple black text can stay as editable text, with the other page content in an embedded picture. Scans and complex pages keep their complete page picture. Review the result before using it in a design.

How to use PDF to SVG

  1. Choose your PDF. Add more than one PDF if you want to process a batch.
  2. Choose SVG content. Editable text where possible keeps supported words as text. Page pictures keeps the entire visible page together.
  3. Leave Pages blank for all pages, or enter a selection such as 1-3,5. Select Create SVG.
  4. Check the preview and any notice about pages that stay as pictures. Select Download SVG files. Multiple pages arrive together in a ZIP.
Options explained
SVG content
Editable text where possible separates simple horizontal black text from its background. Page pictures keeps everything in one image inside the SVG. Neither option turns all graphics into editable vector shapes.
Pages (leave blank for all)
Export the pages you need instead of the entire document. The SVG keeps each selected page’s own shape and orientation; pages are not stretched to match one another.
Preview page
After conversion, choose an exported page to inspect its layout. Fonts in editable text can differ from the PDF. Review important words and numbers before sharing.
Process all files
Run the same page selection and content option on each chosen PDF. A file that cannot be opened is reported separately, while the other files can finish. Download individual results or a batch ZIP.
Limits and supported files

Readable PDF documents. If a password is needed to open the document, use Unlock PDF first. SVG files contain embedded pictures, not fully editable drawings.

Inputs must be smaller than 256 MB. Generated picture data and SVG output are each limited to 128 MB. Large pictures are rendered at up to 200 DPI, with a 12-million-pixel and 4096-pixel side limit per page. These bounds control browser memory; they do not guarantee a large file will finish on every device.

Choose up to 200 pages per conversion. Supported editable text is limited to two million characters per conversion and 10,000 fragments per page. Choose fewer pages when a document exceeds these bounds.

Generated text, rotated pages, saved forms, scans, batches, cancellation and offline conversion were checked in Chromium, Firefox and WebKit on a Mac. These checks do not guarantee results for every document. Check the output in Safari and your design application on your own device.

A batch accepts up to 100 input files and 512 MB total, subject to each converter’s limits. Each multi-page document produces a ZIP of its SVG pages. A batch ZIP can therefore contain smaller ZIP files.

Questions

Is this a fully vector copy of my PDF?

No. Supported text uses SVG text elements, but graphics remain embedded PNG pictures. Scanned, rotated, clipped, coloured or uncertain text stays in the page picture. Choose this tool for page images or simple editable text, rather than exact reconstruction of every PDF shape.

Will the fonts match?

Editable text uses common fonts and preserves the words, positions and measured text widths. Exact fonts and spacing can differ. Page pictures keeps the rendered appearance together, within the picture resolution.

What happens to links and forms?

The export contains only newly generated text and embedded page pictures. Links, form fields, buttons, comments and scripts do not remain interactive. Pages with forms or comments keep a picture so their saved appearance remains visible.

Can I export a scanned document?

Yes. A scan becomes an SVG containing a page picture. It does not gain editable words or sharper details. This tool does not run OCR.

Does conversion upload my PDF?

No. Opening, rendering and saving happen in your browser. The result contains no remote pictures or font downloads. Refreshing the page clears the selected document and conversion result.
