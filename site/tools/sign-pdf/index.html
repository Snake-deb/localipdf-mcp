Sign PDF help

Add a visible signature to a PDF by drawing it, typing it or choosing a signature image. Place it on the page, check the size and download the copy with your signature mark.

How to use Sign PDF

  1. Under Create your signature, choose Draw, Type or Upload.
  2. Select Use signature, then Place on this page. Drag to position it; open Placement options for exact measurements.
  3. Inspect each placement and select Save signed PDF.
  4. Select Download signed PDF and check the visible signature in the saved copy.

Questions

Is this a certificate-based digital signature?

No. This tool adds a visible signature mark. It does not create a cryptographic certificate or verify the signer’s identity. Check the recipient’s requirements before using it for a document that needs certified signing.

Is my signature remembered automatically?

No. Open More options and choose Remember on this device only if you want to save it. Leave this off on shared computers.

Can I draw, type or upload a signature?

Draw or type a signature, or upload a picture of one.

Can I change the appearance of a typed signature?

Choose the appearance and wording of a typed signature.
