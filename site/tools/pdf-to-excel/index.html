PDF to Excel help

Convert tables from PDF bank statements, invoices and reports into an Excel workbook. Keep headings and nearby notes with the table, combine matching sections across pages, and review the cells before saving. Files stay on your device.

How to use PDF to Excel

  1. Choose your PDF, set Pages (leave blank for all) and select Find tables.
  2. Inspect Table to preview and correct detected cells if needed. Choose Export layout and whether matching tables should be combined.
  3. Review the selected tables and original-text option, then select Create Excel file.
  4. Select Download Excel and check the worksheet columns, headings and values.
Options explained
Export layout
Document layout keeps headings and nearby notes with tables. Tables only focuses on the detected cells.
Pages (leave blank for all)
Choose the pages of the statement to inspect.
Table to preview
Switch between detected tables and edit incorrect cells before export; covered merged cells cannot be edited separately.
Combine selected tables with matching headings into one sheet
Join matching sections in page order. A different heading creates a separate worksheet.
Use numbers for amounts and quantities
In document layout, save unambiguous amounts as numbers; leading-zero IDs, dates and long identifiers stay as text.
Include original page text on separate sheets
Keep the extracted text to check for missed content. These sheets have one column, unlike table sheets.
Include this table
Choose which detected tables to include, and use Previous rows or Next rows to inspect longer tables.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.

Questions

Can I convert a bank statement without table borders?

Yes, supported tables with selectable text can use spacing and alignment even without borders. Document export keeps nearby text, joins matching table sections and puts different headings on separate sheets. Check the preview before saving.

Will my numbers and leading zeros stay correct?

Ordinary amounts and quantities can become Excel numbers. Leading-zero codes, dates, long identifiers and ambiguous number formats stay as text. You can turn numeric conversion off.

Can every PDF table be recovered perfectly?

No. Merged cells, unusual columns and complicated layouts can be read incorrectly. Compare the preview with the source, especially totals, dates, account numbers and leading zeros.

What if the PDF is a scan?

Pictures of tables do not contain selectable text for this converter to read. OCR can help recognize the words, but the resulting table still needs review. Keep the original page available for comparison.

How do I combine a bank statement across several pages?

Choose Document layout and select the tables you need. Turn on Combine selected tables with matching headings into one sheet. Matching sections are joined in page order; different headings start another sheet. Compare dates, debit and credit columns, balances and transaction counts with the original.
