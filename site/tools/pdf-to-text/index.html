PDF to Text help

Extract existing selectable text from a PDF and copy it or save it as TXT, Markdown or JSON. Use the output for notes, searching or moving words into another application.

How to use PDF to Text

  1. Choose the PDF and enter a selection in Pages, or leave it blank for the whole document.
  2. Select Extract text and inspect each Preview page for missing or misplaced words.
  3. Use Save as to choose TXT, Markdown or JSON for the extracted text.
  4. Use the Download button for that format, or Copy this page for the current preview.
Options explained
Pages (leave blank for all)
Extract words from all pages or enter a smaller range for a chapter or section.
Preview page
Check the extracted words against the corresponding page before copying them.
Save as
Plain text (.txt) suits simple notes, Markdown (.md) suits text workflows, and JSON (.json) keeps structured page output.
Process all files
Apply these settings to several PDFs. Each file has its own result or error. Use Cancel file or Cancel all files to stop processing, and Download batch as ZIP to save the results together. Check that page positions or form fields suit each file.

Questions

Why is a scanned page missing text?

A scanned page may contain only a picture of the words. This tool reads existing PDF text; it does not recognize text from pictures. Use OCR when the words cannot be selected in a PDF viewer.

Will columns and tables keep their layout?

Text extraction does not guarantee the original reading order or page layout. Review columns, tables and unusual fonts. PDF to Word or PDF to Excel may be more useful when you need an editable document or table.

Can I extract text from only one chapter?

Extract words from all pages or enter a smaller range for a chapter or section.

How can I check whether extracted text is correct?

Check the extracted words against the corresponding page before copying them.
