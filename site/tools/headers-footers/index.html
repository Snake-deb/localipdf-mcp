Headers & Footers

Add page numbers, dates and text above and below your pages.

Enable JavaScript in your browser to use this tool.

Headers & Footers help

Add text above and below your PDF pages. Choose each section separately and use page numbers, the filename, today’s date or your own variables. Existing page text and pictures stay in place.

How to use Headers & Footers

  1. Choose a PDF.
  2. Enter text in Header centre or Footer centre. Open More options for left and right positions.
  3. Use the insertion buttons for page numbers, file names or dates. Check the live preview, then select Add headers & footers.
  4. Check Preview result and download your PDF. For several PDFs, use Process all files.
Options explained
Header and Footer
Centre fields are shown first; left and right fields are in More options. If the text does not fit, shorten it or choose a smaller size.
Insert page number, total pages, file name or date
Click a text box, then use an insertion button. Its label is filled in with the original page number, total pages, file name or today’s date when you save. Typed placeholders still work.
Custom variables
Write name=value, one per line, then use {name} in your text. Unknown or repeated names are reported.
Pages (leave blank for all)
Leave empty for all pages or enter a range such as 1–3, 5. Page numbers refer to the original document, even when only some pages are selected.
Margin (mm)
Distance from the visible page edges in millimetres. Preview the result to avoid covering existing content.
Limits and supported files

Standard PDFs. Switchable layers and XFA forms need a fixed standard copy first.

Up to 128 MB input and output; available browser memory may require less.

Up to 500 pages, with a two-minute deadline. Each text section is one line, up to 1,000 characters, and must fit the visible margins.

Current browsers with local workers. This tool is included in the initial offline cache.

The shared queue processes files independently; failed files do not remove successful results.

Questions

Does this replace my original header?

No. It adds new text. Existing page content remains, so check the preview for overlap.

Are my words and pictures turned into page images?

No. Original selectable text, drawing instructions and image data remain.

Can I use other writing systems?

Standard fonts support their normal characters. Noto Sans supports extended Latin, Greek and Cyrillic. Unsupported characters are reported rather than silently replaced.

What happens to a digital signature?

Saving changes invalidates a cryptographic signature. Acknowledgement is required, and the original file stays unchanged.

Can I use a protected PDF?

A PDF that opens without a password is unlocked locally for editing. If an opening password is required, use Unlock PDF first.
