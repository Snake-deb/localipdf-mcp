RTF to PDF help

Open a rich-text document and turn its text into a readable PDF. Paragraphs, bold, italic and strikethrough are kept. Choose a fresh page layout, check the preview and download a new copy.

How to use RTF to PDF

  1. Select Open RTF file and choose your .rtf document.
  2. Check the Live preview and any messages about formatting or pictures.
  3. Choose the paper size, orientation, text size, line spacing and margins.
  4. Select Create PDF, check every page and select Download PDF.
Options explained
Live preview
Shows the supported text and emphasis. It is a formatting preview; check page breaks in the created PDF.
Paper size and orientation
Choose A4, Letter or A3, in portrait or landscape.
Text size and line spacing
Choose 8–36 points with compact, comfortable or double spacing. The original fonts and text sizes are replaced.
Margins (mm)
Choose 5–50 mm of space around the text.
Process all files
Create one PDF per selected RTF with the current layout. Failed files are reported separately. Download individual copies or a ZIP.
Clear file
Remove the input and result. Browser refresh also clears working files.
Limits and supported files

RTF 1 documents with text and basic emphasis. Legacy code-page bytes and RTF Unicode escapes are read by RTF.js. Output fonts cover Latin, Greek and Cyrillic text; unsupported characters are reported.

Up to 50 KB per file and 50,000 RTF source characters after legacy-byte escaping. Use a smaller section for larger documents.

Up to 500 output pages in the shared builder. Complex RTF layouts and nesting are rejected. These are enforced bounds, not a completion guarantee on every device.

Use a current browser. Measured results for different browsers are recorded separately. Formatting accuracy is not guaranteed for every document.

Up to 100 selected files and 512 MB combined, subject to the per-file limits. One failed file does not stop the others.

Questions

Which parts of my RTF formatting are kept?

This is a text conversion. Paragraphs, bold, italic and strikethrough are kept; fonts, colours, underlines and the original page layout are not. Pictures appear as [Image] labels. Check the preview before saving.

Can I convert RTF tables, fields or drawings?

These are reported as unsupported rather than silently removed. Headers, footers, footnotes, hidden text and raised or lowered text are also unsupported. Export a PDF from your document editor to keep a complex layout.

Do I need RTF source or normal pasted text?

Use Text to PDF for normal pasted text. This tool reads an .rtf document. Open the original file to read its declared character encoding correctly.

Does RTF conversion open linked or embedded files?

No. RTF fields and embedded objects are rejected; external imports are not opened. Pictures are represented by text labels. Document data and filenames stay on your device.

Can RTF conversion run without an internet connection?

Yes, once the app's processing files finish downloading. Refresh clears the working document, so download your result first.
