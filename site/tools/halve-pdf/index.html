Halve PDF pages

Split double-page scans into separate left/right or top/bottom pages.

Enable JavaScript in your browser to use this tool.

Halve PDF pages help

Separate a double-page scan into individual pages. Choose left and right halves or top and bottom halves when a scanner captured two pages together.

How to use Halve PDF pages

  1. Choose a PDF containing two scanned pages on each sheet.
  2. Under Split each page, choose Left and right or Top and bottom.
  3. Set Split position, Page order and Pages to split, then select Split pages.
  4. Inspect the resulting halves and select Download PDF; only selected source pages are included.
Options explained
Split each page
Choose left/right or top/bottom halves to match the scanned spread.
Page order
Choose which half comes first to match the reading direction.
Pages to split
Leave blank to split every source page, or enter ranges such as 1-6, 9. Unselected pages are omitted from the output.
Split position
Move the dividing line away from the middle when the two scanned pages have unequal widths or heights.
Center split
Return the split line to the middle at 50%.
Create a print copy without a valid digital signature. I’ll keep the signed original.
Shown for digitally signed input. Continue only when you want an edited copy; preserve the signed original for verification.
Process all files
Choose multiple files to use the settings above on each one. Results and failures appear separately. Use Cancel file, Cancel all files or Download batch as ZIP as needed. Check that page positions or form fields suit every input.
Limits and supported files

PDF documents. An opening password is required when the file needs one to be read.

Local tests used synthetic 10, 50, 100 and 200 MB PDFs containing large images. Chromium: completed 10, 50, 100, 200 MB. Firefox: completed 10, 50, 100, 200 MB. WebKit: completed 10, 50, 100 MB; 200 MB did not complete. Earlier 200 MB WebKit attempts hit a file-read error; try a smaller document if this happens.

The page-halving tool accepts documents with up to 500 pages. Chromium, Firefox and WebKit: completed 50, 300 text pages; 1000 text pages did not complete.

Halve PDF was tested on a 16 GB Mac with Chromium, Firefox and WebKit. “Did not complete” includes input limits, errors and test timeouts; try a smaller selection. These are observed examples, not guaranteed limits on your device. WebKit tests do not replace a check in Safari on your own device.

Up to 100 input files and 512 MB total; up to 200 output files or 512 MB. ZIPs over 128 MB need Chrome/Edge direct disk saving; use individual downloads in other browsers. The Workflow stress test completed 100 synthetic files in all three engines; this does not guarantee the same capacity for every conversion.

Questions

Is this the same as Split PDF?

No. Halve PDF pages divides the visible area of a page into parts. Split PDF separates existing whole pages into files. Use the tool that matches how your source document was scanned.

Is halving a way to redact information?

No. Treat it as a page-layout change, not secure content removal. Check the page boundary for cut-off words, and use Redact PDF if information must be removed permanently.

Can I split a scanned book spread into two pages?

Choose left/right or top/bottom halves to match the scanned spread.

Can I change which half comes first?

Choose which half comes first to match the reading direction.
