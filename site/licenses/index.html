PDF/A archives

Picture-based PDF/A-2b copies use the existing PDF.js renderer and pdf-lib writer, with an unchanged sRGB2014 colour profile. Profile terms, source and checksum are available here. veraPDF is used for independent development checks and is not shipped in the browser.

Fast Web View

QPDF 12.4.2 runs locally as WebAssembly for PDF linearization. The upstream engine is unchanged; localipdf supplies a worker adapter and gzip transport compression. QPDF uses Apache-2.0, with linked zlib and Independent JPEG Group component terms. This software is based in part on the work of the Independent JPEG Group. Full notices include the generated Emscripten and C/C++ runtimes. No GPL-only QPDF component is shipped.

Fonts, image codecs and OCR

Additional notices cover PDF.js codecs and fonts, MozJPEG, Zopfli, Tesseract, Leptonica, PaddleOCR, ONNX Runtime, OpenCV, Workbox, Noto fonts, and the Figtree font used for the site's text. Some tools download these components only when needed. The complete texts below include component-level terms, not only the package’s top-level licence.

GPL alternatives and covered source

JSZip is offered under MIT or GPL-3.0-or-later. localipdf uses the MIT option. The audit found no GPL-only or AGPL runtime in the delivered app. Tools used only for local development or comparison tests are not included merely because they ran on a developer’s machine.

ONNX Runtime 1.24.3 names Eigen under MPL-2.0 in its third-party notices. Its pinned source is provided here with the upstream build patches and original file-level notices, without charge:

localipdf changes the Zopfli JavaScript wrapper to export its existing runtime for browser use. The neural OCR worker’s generated JavaScript wrappers are adapted for the site’s Content Security Policy; the model and engine notices are preserved. These changes do not modify Eigen source.
