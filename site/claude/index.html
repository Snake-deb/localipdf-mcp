Use localipdf in Claude & Codex

Ask Claude or Codex to work on PDFs on your computer. Both use the same localipdf MCP server and PDF tools. Download the package for your app.

Download for Claude DesktopAbout 13 MB. For Mac and Windows. Needs Google Chrome or Microsoft Edge.

Download for CodexSame server in a ZIP. Needs Node.js 20 or newer and a supported browser.

Codex setup guide

Install in Claude Desktop

Install Claude Desktop. Choose Download for Claude Desktop above and open the file. Claude Desktop shows what the extension can do. Confirm to install it.

Install in Codex

Choose Download for Codex, extract the ZIP and keep its files together. Follow the Codex setup guide above to register server.mjs as a local MCP server, reload the connection and test with disposable PDFs. If you already extracted the Claude package, you can reuse that folder.

What you can ask

Name the file and the task. For example: “Make report.pdf in my Downloads smaller than 1 MB” or “Merge invoice.pdf and receipt.pdf on my Desktop.” The result is saved next to your file. Your original stays unchanged.

Tools you can use

Most tools work, including Compress PDF, Merge PDF, Split PDF, Protect PDF, PDF to Word, Annotate PDF, Edit PDF and Redact PDF. Sign PDF, Organize PDF, Compare PDFs, PDF Overlay, Scan to PDF, PDF Workflow and PDF Reader work on this website only. Text recognition (OCR) is not included.

Confirming an action

Your app may ask before running a tool. Some steps also need your own answer, such as confirming that you may unlock a PDF or that a redaction is final. Review the action before confirming it.

What stays on your computer

PDF processing runs in a separate temporary browser profile on your computer. The assistant receives what you type and what the tools report, including file paths and messages. Some operations, such as Edit PDF, also return document text. Your AI client’s data policies apply to that information.

Updates and warnings

The extension does not update itself. When we improve the tools, download it again. Claude Desktop may show a warning because this extension is not listed in its directory.

Other local MCP apps

The same server can be configured in compatible local MCP clients, including Claude Code. These clients need Node.js 20 or newer. Extract the ZIP and register server.mjs as a local STDIO server.
