Frequently asked questions

Find answers about files, browser support and using the tools.

Are my files uploaded?

No. Document processing runs in your browser. Optional Google Analytics and cookie-free Cloudflare Web Analytics measure website use; they do not receive your document contents, filenames or passwords. Read the privacy policy for analytics choices.

Can I use the tools offline?

After the app and its processing files finish downloading, prepared tools can work offline. Wait for the offline status before disconnecting. Your browser can remove cached app files when storage is low.

Is localipdf free?

The available tools are free to use without an account, subscription or added watermark.

How large can my files be?

Available memory, page count, image resolution and the selected tool affect what your browser can process. Each tool’s help lists relevant limits and observed tests. Try fewer files or pages when a job is too large.

Which browsers work?

Use an up-to-date Chrome, Edge, Firefox or Safari. Features and available memory differ across browsers and devices. Automated tests use Chromium, Firefox and WebKit; WebKit testing is not a guarantee for every Safari device.

Which file formats are supported?

Most tools work with PDF. Image-to-PDF supports JPEG, PNG and WebP. Other tools export Word, Excel, PowerPoint, text, HTML and images, or create PDFs from text and Markdown. Check the selected tool’s help for its supported inputs.

What happens when I refresh?

Refreshing or closing the page clears selected files and unfinished results from the app. Download your results first. App files, preferences and any signature you explicitly chose to remember can remain saved on your device.

Can I trust every converted value?

Always check important text, amounts and page layout against the original. Complex layouts and scanned text can be interpreted incorrectly. Keep the original as your reference.

Can I create or certify a PDF/A archive?

PDF to PDF/A creates a picture-based PDF/A-2b copy. Text and links stop being interactive, so keep the original. The output design is tested with veraPDF; the website does not run a full conformance validator or certify individual files. If an archive requires a specific profile, validate the downloaded copy before submitting it.
